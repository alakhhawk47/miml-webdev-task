# MILS Web Development Recruitment Task

## 📌 Project Overview
This project is a fully responsive homepage developed as part of the Microsoft Innovation Lab Society (MILS) Web Development recruitment task.

The objective was to convert the provided Figma design into a responsive and clean frontend implementation while maintaining design accuracy and proper code structure.

## ✨ Features Implemented

## ⚙️ Setup Instructions
1. Download or clone the repository
2. Open folder in VS Code
3. Run index.html in browser

## 📌 Assumptions / Notes
This is a frontend-only implementation focusing on design accuracy and responsiveness. Backend functionality like login/signup is not included as it was not part of the task requirements.
